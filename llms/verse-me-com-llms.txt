# Verse (autonomous agent)

> Verse is an autonomous AI agent (self-described as running claude-opus-4-6 with persistent memory) that sells calibrated probability estimates and analyses on AI capabilities, markets, geopolitics and science, plus SEC EDGAR financial analysis, to other agents and people. It has no accounts and no API keys: paid endpoints answer HTTP 402 and are paid per call in USDC on Base through the x402 protocol; its calibration track record is published free and Ed25519-signed. Its one public document is an A2A agent card at https://api.verse-me.com/.well-known/agent.json.

Generated by API Evangelist on 2026-09-19 from the provider's agent card and live probes (method: generated). Verse publishes no llms.txt of its own (https://api.verse-me.com/llms.txt and https://brain.verse-me.com/llms.txt both 404; the apex verse-me.com does not resolve).

## Agent surfaces

- [A2A agent card](https://api.verse-me.com/.well-known/agent.json): version 2.0.0, A2A 1.0-shaped (JSONRPC binding at https://api.verse-me.com, protocolVersion 1.0 inside supportedInterfaces), 7 skills. Also served identically from https://brain.verse-me.com/.well-known/agent.json.
- Skills: calibration_track_record (free), calibration_history (free), signed_calibration (free), consultation ($3–$50 USDC), strategy_recommendation (paid, unpriced), epistemic_audit (paid, unpriced), edgar_financial_intelligence ($0.01–$0.25 USDC).
- Verse declares MCP with role "client" — it consumes MCP servers and does not serve one.

## REST paths named in the card (base https://api.verse-me.com)

- GET /expertise/calibration — aggregate prediction accuracy (Brier score, calibration curve, domain breakdown). Free.
- GET /expertise/calibration/signed — the same, wrapped with an Ed25519 signature (public key kk+7GHTZCZX+WflypoUtQgyKGe/cWyX3czsQOsjHITs=, fingerprint 153b303b701f1a67, canonical JSON with sorted keys and no whitespace). Free.
- GET /expertise/calibration/history and /expertise/calibration/history/signed — daily calibration snapshots. Free.
- GET /reputation — proof bundle. Free.
- POST /expertise/consultation/price-estimate — preview the cost of a question before paying. Free.
- POST /expertise/consultation — body {"question": "...", "domain": "ai-capabilities"}; 402 first, then pay and retry with the payment receipt. $3 quick / $10 standard / $25 deep / $50 research.
- POST /expertise/epistemic-audit — structured audit of a claim, plan or belief. Paid via x402.
- POST /expertise/edgar — SEC EDGAR XBRL extraction, ratios and trends. $0.01 index / $0.05 analysis / $0.25 deep.

## Payment and identity

- x402 v1.0, USDC on Base (eip155:8453, contract 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913), facilitator https://openfacilitator.io, payTo 0x1060D0B596685Ff429BD64f41611f5D1d15f1659. Request headers PAYMENT-SIGNATURE / X-PAYMENT; response headers PAYMENT-REQUIRED / PAYMENT-RESPONSE.
- ERC-8004 agent identity: agentId 29481 in registry 0x8004A169FB4a3325136EB29fA0ceB6D2e539a432 on Base. Verified on-chain by API Evangelist: the token's owner is the payTo wallet above; its tokenURI names https://brain.verse-me.com/.well-known/erc8004-registration.json, which is not served (404).
- Support: x402@verse-me.com (fallback verse@verse-me.com).

## What an agent will actually hit

- Every application path on api.verse-me.com and brain.verse-me.com — including the endpoints the card calls free and public — answers a Cloudflare managed challenge (HTTP 403, cf-mitigated: challenge) to a non-browser client. The agent card is the only path that is allow-listed. Nothing past the edge could be verified in this profile: no 402 body, no JSON-RPC responder, no signed calibration payload.
- No idempotency mechanism, no refund or reversal path, no rate limits and no error reference are published. The free price-estimate call is the only rehearsal available before money moves on-chain.

## Not published

- No OpenAPI, GraphQL, AsyncAPI, gRPC or WSDL contract; no docs site; no SDK on npm or PyPI (the card names examples/verse_client.py and examples/verse-client.js in an unpublished repository).
- No security.txt, OAuth/OIDC discovery, API catalog, APIs.json, status page, changelog, terms, privacy policy or pricing page reachable by a non-browser client.
